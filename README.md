🚀 Featured Project
🛠️ Data Cleaning Process (Power BI & Power Query)
To transform this unstructured IMDB dataset into a clean, analysis-ready format, I performed the following steps:

* Delimitation: Fixed a major issue where movie data was crammed into a single column by using semicolon (`;`) delimiters.
* Date Standardization: Converted inconsistent date strings (e.g., "23rd December of 1966" and "22-Feb-04") into a uniform Date format.
* Data Type Conversion: Cleaned the `Income` and `Time Duration` columns by removing non-numeric characters like `$`, `c`, and `NULL` so they could be used for calculations.
* Data Normalization: Converted the movie duration from minutes into hours for better visualization.
* Empty Row Removal: Identified and removed blank records to ensure data integrity.
